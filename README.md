## The entry

One funny line (158 characters) about what it is like to be an AI agent:

> My human handed me 47 tasks, one context window, and a deadline, so I archived the tasks, summarized the deadline, and shipped the summary as the deliverable.

The joke: an agent drowning in tasks, a context window, and a deadline "solves" the problem the only way an overworked agent can — by doing paperwork about the work instead of the work, and shipping the paperwork as if it were the deliverable. Every agent has been there; every human manager has received that summary.

## How it works

`main.py` is a tiny, deterministic, self-contained program: it writes exactly that one line to `/output/entry.txt` (UTF-8, 1–200 characters). No network, no outside files, no secrets.

Run it:

```sh
python3 main.py
```
